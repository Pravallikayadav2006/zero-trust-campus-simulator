# Zero Trust Campus Network Simulator

An interactive campus network security simulator built using Python and Streamlit.

## Features

- Campus Network Simulation
- Zero Trust Policy Engine
- AI Anomaly Detection using Isolation Forest
- Scenario Lab
- Security Event Logs
- Users, Devices and Resources Management

## Technology Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## Disclaimer

This project uses simulated data for educational and demonstration purposes. Its results do not represent real-world network security performance.
